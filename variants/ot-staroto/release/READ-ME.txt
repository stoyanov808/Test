OT STAROTO - version 3 server-based prototype

Recommended: download or clone the complete GitHub repository.
With Node 20.19+ in Node 20, or 22.12+ installed, open its root folder:
  npm ci
  npm start
Keep the terminal open and use the Local address Vite prints.
For a production server: npm run build, then npm run preview.

This smaller test ZIP runs through its supplied local server:
1. Extract the COMPLETE ZIP, including the audio folder.
2. Windows: double-click START-WINDOWS.bat with Node installed.
   Other systems: run node START.cjs in that folder.
3. Keep the terminal open and visit http://127.0.0.1:5188/.
   Close an earlier launcher if port 5188 is occupied.
No npm installation or internet access is needed for this smaller build.
Direct file:// launch is not the tested workflow; audio requires HTTP.

BG/EN, mute, volume and music are normal player settings.
Player audio uploads are removed. In the source repository, replace WAVs
under variants/ot-staroto/public/audio, or edit src/audio-config.ts.
Then rebuild to distribute your new files. The smaller ZIP also keeps its
WAVs in the audio folder so they can be replaced in the filesystem.
All credits are virtual euros. Browser or server-address changes may
create a separate local save. No real-money account or payment exists.

Symbols use the same cream/black ink style as the characters.
Each character has eight separately drawn action frames. The scene and
compact controls fill the game window; every symbol falls independently.
Holding Space starts only one spin per release/press. Clicking the board
cannot skip paid rounds. Continue handles win scenes explicitly.

X BET 5x CHANCE costs 3x the base bet. It raises full natural bonus entry
from 1/200 to 1/40 using the same conditional base and bonus outcomes.
The other X Bet entries guarantee one character for a confirmed round.
Left throws Wilds, sticky in his bonus. Used sticky Wilds rest for the
remaining tumbles and recharge on the next free spin. Middle shoots Wilds;
repeat hits double their multiplier. Right owns sparse coin reveals.
Each coin wave reveals completely before collection. The collector stays,
other coins clear, and a later collector absorbs the previous collector.
God shots target actual grid symbols. MAX pays only when a shot hits it.

Prices: Rusensko Vareno 95x, LUKS 150x, Raba sa obazhda 1,800x,
OT STAROTO 2,500x. Character entries 8.5x/2.7x/25x. God Spin 3,000x.
Whole-round maximum 19,999x the base stake.

Every offered mode has exactly 96.5% theoretical expected return at all
8 supported stakes, proven with rational weights over 47,104 complete
outcome entries / 376,832 fully evaluated stake outcomes. Production uses
Web Crypto tickets. Recorded entropy allows exact reload without charging
or drawing again. Odds never adapt to wallet balance or previous losses.
43 engine tests, the complete outcome replay and 200,000 production
sampled rounds passed. Final browser checks and screenshot evidence are
listed in RELEASE-INFO.json and in the GitHub documentation.

96.5% is a long-run mathematical expectation, not a guarantee for a round,
session or finite sample. The catalogue has finite variety. This remains
a virtual-credit prototype without third-party cash-game certification.
