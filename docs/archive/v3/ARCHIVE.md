# Version 3 archive

These files preserve the committed version3 design, public-reference research and measured results before restoring verified source-only normal xWays and smooth top-drop presentation. Version3 used source-plus-one normal badges, a common revealed type per drop, and upgraded arrivals only with the infection perk. They describe `studentski-duck-3`, not the current game. The original README is retained verbatim; its repository-root links should be read from the historical commit recorded in [the archive receipt](archive-receipt.json).

The public paytable evidence is copied unchanged. Its official-source facts continue to apply, while sampler probabilities, normal-badge targets, continuation pricing, presentation and measured results can differ in later versions. Current documentation is in the parent `docs` directory.
